Official Demos & Guide

teckgeekz-consent

A lightweight, modular, and accessible cookie compliance plugin for modern web applications.

Maintained and enhanced by Teckgeekz • GitHub Repository

Implementation Steps (Overview)

1

Include Assets

Link cookieconsent.min.css in your <head> and cookieconsent.min.js before </body>.

2

Select Compliance Mode

Choose info (acknowledgement), opt-out (default allowed), or opt-in (strict GDPR/Google Consent Mode).

3

Style & Position

Configure banner vs floating, choose built-in themes (block, classic, edgeless), or pass custom palette colors.

4

Handle Events

Hook into onInitialise, onStatusChange, and onRevokeChoice to dynamically control scripts and tracking tags.
